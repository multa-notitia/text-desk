# Text Desk

The page for reading, editing and rating Project Mystery's quest text and voice lines: https://multa-notitia.github.io/text-desk/

This repo holds only the page's code. The game's text, recordings and ratings stay in the private game repo, and the page reads them with a GitHub token kept in your own browser. The source lives in `tools/text_desk/` of the game repo; copy `index.html` and `core.js` here after changing them.
